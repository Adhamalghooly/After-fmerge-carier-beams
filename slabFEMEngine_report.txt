WHAT WAS DONE
-------------
Goal: Fix Phase 2 edge force extraction, which was producing
      ~3,473 kN total instead of the expected 250 kN (~14x error).

Root Cause:
  The original approach integrated Mindlin shear stresses (Qx, Qy)
  along element boundary edges. Standard Mindlin quad elements produce
  spurious shear oscillations at element edges — a known locking
  artefact — giving values 14x too large at boundary Gauss points.

Fix Applied:
  Replaced stress integrals with exact nodal reactions.

  Formula:
    R_i = K * d - F_applied    (at each fixed support node i)

  This is mathematically exact. No approximation beyond the FEM mesh.

  Additional fix — Junction Splitting:
    Where two beams meet at a corner, the plate produces a "corner
    force" (the slab tends to lift at corners — classical Kirchhoff
    plate effect). The corner node reaction is split 50/50 between
    the two beams meeting there. Without this the total was 313 kN
    instead of 250 kN.

  Additional fix — Column Node Tracking:
    Added atColumn flag to mesh nodes. Column nodes are excluded from
    beam load summation (their reaction goes to the column directly).

FILES CHANGED
-------------
  types.ts       — added atColumn: boolean to FEMNode
  mesh.ts        — exposes atColumn on each node; fixes beam-line
                   nodes (including interior beams) so reactions can
                   always be extracted
  edgeForces.ts  — complete rewrite: signed nodal reactions +
                   junction splitting
  beamMapper.ts  — updated to use new reactions structure from Phase 2
  index.ts       — passes beams list to Phase 2; fixed equilibrium
                   sign check
  validation.ts  — fixed equilibrium sign check (Math.abs on sum)

------------------------------------------------------------
SIGN CONVENTION
------------------------------------------------------------
  R_i < 0  ->  support pushes slab UP  (beam carries downward load)
  R_i > 0  ->  corner force, plate lifts (tie-down, not gravity load)
  Output w(x): positive = downward load on beam (engineering sign)
