1. OVERVIEW
───────────────────────────────────────────────────────────────────────────────

Phase 7 implements a FULL MONOLITHIC coupled beam-slab finite element system,
where slab shell elements and 3D beam frame elements share a single global
stiffness matrix and are solved simultaneously.

This directly replicates the ETABS beam-slab interaction behavior:
  • No load-transfer approximations (Phases 1–6 approach)
  • No sequential slab→beam transfer
  • Exact compatibility enforced at the slab–beam interface
  • Beam stiffness feeds back into slab response (and vice versa)

2. THEORETICAL FORMULATION
───────────────────────────────────────────────────────────────────────────────

2.1  Slab Element (unchanged from Phases 1–6)
─────────────────────────────────────────────
  • 4-node Mindlin-Reissner bilinear quadrilateral shell
  • 3 DOF per node: [UZ, RX, RY]
    – UZ  = transverse deflection (mm)
    – RX  = rotation about global X  (≈  ∂w/∂y, rad)
    – RY  = rotation about global Y  (≈ −∂w/∂x, rad)
  • Shear-locking free: 2×2 Gauss for bending, 1×1 for shear
  • Material: Ec = 4700√f'c (MPa), ν = 0.20 (ACI 318-19 §19.2.2)
  • Total slab DOFs: 3 × n_slab_nodes

2.2  Beam Frame Element (NEW — Phase 7)
───────────────────────────────────────
  • 2-node 3D Euler-Bernoulli frame element
  • 6 DOF per node: [UX, UY, UZ, RX, RY, RZ]
  • Total element DOF: 12  (indices 0–11 as in McGuire, Gallagher & Ziemian)

  DOF ordering per node:
    u = axial displacement (along beam local-x axis)
    v = lateral displacement (local-y, horizontal perpendicular)
    w = vertical displacement (local-z = global Z for horizontal beams)
    θx = torsional rotation about local-x
    θy = bending rotation about local-y  (convention: θy = −∂w/∂x_local)
    θz = bending rotation about local-z  (in-plane)

  Local 12×12 stiffness K_local (McGuire Table 4-1):

    Axial block [u1, u2]:
      K[0,0] = K[6,6] = EA/L;  K[0,6] = K[6,0] = −EA/L

    Torsion block [θx1, θx2]:
      K[3,3] = K[9,9] = GJ/L;  K[3,9] = K[9,3] = −GJ/L

    Bending about z [v1, θz1, v2, θz2] — in-plane:
      K[1,1] = K[7,7] = 12EIz/L³
      K[1,5] = K[5,1] = K[1,11] = K[11,1] =  6EIz/L²
      K[7,5] = K[5,7] = K[7,11] = K[11,7] = −6EIz/L²
      K[5,5] = K[11,11] = 4EIz/L;  K[5,11] = K[11,5] = 2EIz/L

    Bending about y [w1, θy1, w2, θy2] — vertical (strong axis):
      K[2,2] = K[8,8] = 12EIy/L³
      K[2,4] = K[4,2] = K[2,10] = K[10,2] = −6EIy/L²  (negative: θy=−∂w/∂x)
      K[4,8] = K[8,4] = K[8,10] = K[10,8] =  6EIy/L²
      K[4,4] = K[10,10] = 4EIy/L;  K[4,10] = K[10,4] = 2EIy/L

  Cross-section properties (mm units):
    A  = b × h
    Iy = b × h³ / 12  (strong axis, vertical bending)
    Iz = h × b³ / 12  (weak axis, in-plane bending)
    J  = (bMin³ × bMax/3) × (1 − 0.63·r + 0.052·r⁵)  where r = bMin/bMax
         (Saint-Venant torsion, Timoshenko & Goodier approximation)

2.3  Coordinate Transformation
───────────────────────────────
  For a beam with direction angle α from global X (horizontal beams: α=0°;
  vertical beams: α=90°):

    Local frame:
      local-x = [cos α, sin α, 0]  (beam axis)
      local-y = [−sin α, cos α, 0] (horizontal perpendicular)
      local-z = [0, 0, 1]          (vertical = global Z)

    3×3 rotation matrix R (transforms global → local):
      R = [[ cos α,  sin α, 0 ],
           [−sin α,  cos α, 0 ],
           [   0,       0,  1 ]]

    12×12 transformation matrix T = block_diag(R, R, R, R)

    Global stiffness: K_global = Tᵀ · K_local · T

  Verification for X-beam (α=0°): R = I → K_global = K_local ✓
  Verification for Y-beam (α=90°): R = [[0,1,0],[−1,0,0],[0,0,1]]
    → Local w maps to global Z ✓
    → Local θy maps to −global RX ✓ (beam slope along Y = RX_slab)

2.4  Penalty Coupling Constraints
──────────────────────────────────
  At each slab mesh node that lies on a beam, the following equality
  constraints are enforced via the penalty method:

    UZ_slab_i  = UZ_beam_j    (vertical deflection compatibility)
    RX_slab_i  = RX_beam_j    (rotational compatibility about global X)
    RY_slab_i  = RY_beam_j    (rotational compatibility about global Y)

  These are in GLOBAL coordinates. The transformation matrix ensures that
  the local beam bending slope is correctly coupled to the slab rotation:
    • For X-beams: RY_global captures the bending slope ∂w/∂x ✓
    • For Y-beams: RX_global captures the bending slope ∂w/∂y ✓
    • Torsion: for X-beams RX_global = torsion; for Y-beams RY_global ✓

  Penalty potential energy:
    W_p = (α_p/2) · (g)²  where  g = DOF_slab − DOF_beam

  Resulting stiffness contribution (for each constraint pair [dof_s, dof_b]):
    K[dof_s, dof_s] += α_p
    K[dof_b, dof_b] += α_p
    K[dof_s, dof_b] -= α_p    (off-diagonal: negative = equality enforcement)
    K[dof_b, dof_s] -= α_p    (symmetric)

  Penalty factor:
    α_p = max(K_diagonal) × penalty_multiplier
    Default penalty_multiplier = 1e4 (constraint accuracy < 0.01%)
    Range: 1e3 (faster, less accurate) to 1e6 (more accurate, may ill-condition)

  Conditioning note: with max diagonal ~1e6 N/mm and α_p = 1e10,
  condition number ≈ α_p / min_eigenvalue ~ 1e10, safely within the
  double-precision limit (machine epsilon ~1e-16, so κ ≤ 1e12 is stable).

2.5  Global DOF Layout
───────────────────────
  Block 1 (Slab):  DOFs 0 … 3·n_slab − 1
    Node i: DOF[3i+0] = UZ, DOF[3i+1] = RX, DOF[3i+2] = RY

  Block 2 (Beam):  DOFs 3·n_slab … 3·n_slab + 6·n_beam − 1
    Beam node j: DOF[3·n_slab + 6j+0] = UX_glob
                 DOF[3·n_slab + 6j+1] = UY_glob
                 DOF[3·n_slab + 6j+2] = UZ_glob
                 DOF[3·n_slab + 6j+3] = RX_glob
                 DOF[3·n_slab + 6j+4] = RY_glob
                 DOF[3·n_slab + 6j+5] = RZ_glob

  Beam nodes = all unique slab mesh nodes with beamId ≠ null.
  Junction nodes (shared by two beams) get ONE 6-DOF beam block entry,
  ensuring full continuity of beams at intersections.

2.6  Boundary Conditions
─────────────────────────
  Slab fixed nodes (columns, isFixed=true):
    → Fix slab DOFs [3i, 3i+1, 3i+2] = 0

  Beam nodes at column positions (isFixed=true):
    → Fix all 6 beam DOFs at that node = 0  (fully clamped beam ends)
    → The penalty constraint is trivially satisfied (0 = 0)

  Isolated beam DOFs (zero diagonal, no element connectivity):
    → Fixed to prevent singular matrix

2.7  Linear Solver
───────────────────
  Gaussian elimination with partial pivoting (solver.ts, Phase 1).
  Dense O(n³) algorithm — suitable for n < ~1500 DOF.
  Convergence criterion: max |K·d − F| < 1e-6

  Performance estimates (5×5 m slab):
    meshDensity=2 → n ≈  627 DOF →  < 5 s
    meshDensity=3 → n ≈ 1100 DOF → ~15 s
    meshDensity=4 → n ≈ 1827 DOF → ~60 s (not recommended for coupled system)

2.8  Element Force Recovery
────────────────────────────
  For each beam element [nodeA, nodeB]:
    d12_global = [d_nodeA (6 DOF), d_nodeB (6 DOF)]  from d_full
    d12_local  = T · d12_global
    f12_local  = K_local · d12_local

  Result vector f12_local = [N1, Vy1, Vz1, T1, My1, Mz1, N2, Vy2, Vz2, T2, My2, Mz2]
    N   = axial force
    Vy  = shear in local-y (in-plane)
    Vz  = shear in local-z (vertical) ← primary output for design
    T   = torsion
    My  = bending about local-y (vertical bending) ← primary for design
    Mz  = bending about local-z (in-plane)

3. VALIDATION TESTS
───────────────────────────────────────────────────────────────────────────────

3.1  Test 1 — Frame Element Cantilever Self-Test
─────────────────────────────────────────────────
  Configuration:
    Beam: b=300mm, h=500mm, L=5000mm, f'c=25MPa
    Ec = 4700√25 = 23500 MPa
    Iy = 300×500³/12 = 3.125×10⁹ mm⁴
    Load: P = 100 kN downward at free end (node 2)

  Analytical (Euler-Bernoulli):
    δ_tip = PL³/(3EI) = 100000×5000³/(3×23500×3.125e9) = X mm
    θ_tip = PL²/(2EI) = Y rad

  Acceptance criterion: |FEM − Analytic| / Analytic < 0.1 %

  EXPECTED RESULT: PASS (exact Euler-Bernoulli element, no shear deformation)

3.2  Test 2 — Coupled System Equilibrium (5×5 m)
──────────────────────────────────────────────────
  Configuration:
    Slab: 5×5 m, t=150mm, f'c=25MPa
    4 corner columns, 4 edge beams (b=300, h=500mm)
    Load: q = 10 kN/m²  →  Total = 250 kN
    meshDensity = 2

  Check: Sum of column reactions = Total applied load
  Acceptance criterion: Equilibrium error < 2 %

  EXPECTED RESULT: PASS
    (Column reactions from slab DOF fixed nodes should balance the total load.
     Beams only redistribute, not add/remove vertical force.)

3.3  Test 3 — Beam Stiffness Contribution
───────────────────────────────────────────
  Configuration: Same as Test 2
  Comparison: Phase-7 coupled max deflection vs. Phase-1 uncoupled (slab only)

  Physical expectation: The beams add stiffness to the system, so:
    δ_coupled < δ_uncoupled

  Acceptance criterion:
    a) δ_coupled < δ_uncoupled (beams reduce deflection)
    b) Deflection reduction > 0 %
    c) Equilibrium error < 2 %

  EXPECTED RESULT: PASS
    (Beams add vertical stiffness at their nodes via K_beam.  Even with
     pinned column BCs on the slab, the beam stiffness raises the effective
     support stiffness at beam nodes, reducing peak deflection.)

3.4  Test 4 — Internal Beam Load Share (6×6 m)
────────────────────────────────────────────────
  Configuration:
    Slab: 6×6 m, t=150mm, f'c=25MPa
    4 corner columns, 4 edge beams + 1 internal Y-beam at x=3000mm
    Internal beam: b=300, h=600mm (deeper than edge beams)
    Load: q = 10 kN/m²  →  Total = 360 kN
    meshDensity = 2

  Checks:
    a) Equilibrium error < 2 %
    b) Internal beam found in results
    c) Internal beam shows positive bending moment (carries load)
    d) Internal beam max shear > 5 kN (significant load share)
    e) Max slab deflection > 0 (non-trivial solution)

  EXPECTED RESULT: PASS
    (A stiffer internal beam attracts more load from the slab.
     With h=600mm vs edge beams h=500mm, the internal beam should
     carry a disproportionately large fraction of the total load.)

6. COMPARISON WITH PHASES 1–6
───────────────────────────────────────────────────────────────────────────────

  Phase 1: FEM slab solve, fixed at columns.  Beams not modeled.
  Phase 2: Extract slab reaction forces → beam distributed loads.
  Phase 3: Map forces to beam w(x) profile.
  Phase 4: Stress-based shear-only transfer (Qx, Qy at edges).
  Phase 5: Full moment-consistent stress transfer (Fz + Mx + My).
  Phase 6: Rotational coupling correction (spring feedback).

  Phase 7 (NEW): Monolithic coupled system.
    • Replaces sequential transfer with simultaneous solution.
    • Slab and beam deflections are mutually consistent by construction.
    • No normalization, no force redistribution approximation.
    • Physically equivalent to ETABS T-beam slab-beam interaction.
    • More computationally expensive (O(n³) solver on larger system).
    • Recommended meshDensity = 2 for practical run-time.

8. KNOWN LIMITATIONS AND FUTURE WORK
───────────────────────────────────────────────────────────────────────────────

  a) Dense solver only: O(n³) Gaussian elimination limits practical meshDensity
     to 2–3 for the coupled system.  A sparse Cholesky solver would enable
     density 4+ without interface changes (solver.ts API unchanged).

  b) ACI stiffness modifiers not applied: The coupled system uses full gross
     section stiffness (EI_full).  ACI 318-19 §6.6.3.1 recommends 0.35EI for
     beams and 0.25EI for slabs under factored loads.  These can be applied as
     a multiplier on E*I values in sectionFromBeam() without structural change.

  c) Single-slab coupling: Phase 7 solves each slab with its associated beams
     as an independent system.  Multi-slab coupling (through shared beams) is
     not yet implemented but follows naturally from the global DOF extension.

  d) Geometric nonlinearity: Not considered.  Phase 7 is a linear elastic
     analysis consistent with ETABS linear static analysis.

  e) Column stiffness: Beam ends are fully fixed (clamped) at column positions.
     Column rotational stiffness could be modeled by replacing the fixed BC with
     a rotational spring kθ = 6EI_col/L_col, improving accuracy for frames
     where column stiffness affects beam moment distribution.
