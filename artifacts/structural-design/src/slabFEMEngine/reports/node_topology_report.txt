A. NODE REGISTRY IMPLEMENTATION
────────────────────────────────────────────────────────────────────────

  Function : GlobalNodeRegistry.getOrCreateNode(x, y, z)
  Location : src/slabFEMEngine/nodeRegistry.ts

  Node structure:
    { id, x, y, z, connectedElements[] }

  Lookup algorithm:
    1. Hash coordinate to grid cell key  round(x/tol) _ round(y/tol) _ round(z/tol)
    2. Probe 27 neighbouring cells (3×3×3) to handle grid-boundary floating-point
    3. If existing node within tol (1e-6 mm) → return its id
    4. Otherwise → create new node, store in bucket, return new id

  Changes to mesh.ts:
    • meshSlab() now accepts optional GlobalNodeRegistry parameter
    • Every grid intersection calls reg.getOrCreateNode(x, y, 0)
    • Local node.id = slab-local array index (existing DOF indexing unchanged)
    • node.globalId = registry-assigned ID (cross-slab unique)
    • After each element is built, reg.registerElement() records connectivity
    • meshMultipleSlabs() creates ONE registry for ALL slabs

  Backward compatibility:
    • When no registry is passed, a private local registry is created
    • In that case globalId === id — all callers work unchanged
