D. LOAD TRANSFER VALIDATION
═══════════════════════════════════════════════════════════════════════════════

Step 1 — Secondary beam B reaction (first iteration, approximate):
  wu_B   = 40.8 kN/m,  L_B = 6 m  (example)
  R_I(B) = 3 × wu_B × L_B / 8  = 3 × 40.8 × 6 / 8  = 91.8 kN   ← P

Step 2 — Point load application on frame F1:
  P = 91.8 kN is placed on element A1 at position a = A1.length = 5 m
  (i.e., at the right end of A1, which is node N1 = junction C2)

  Fixed-end forces from point load at a = L₁:
    using pointLoadFixedEndForces(P, a=L₁, L=L₁):
    b = L₁ - a = 0
    R_I_ptload = P·b²(3a+b)/L³ = P·0·(...)  = 0 kN
    R_J_ptload = P·a²(a+3b)/L³ = P·L₁²·L₁/L₁³ = P = 91.8 kN   ✓

  All of P is transferred as a downward nodal force at N1 (junction):
    Global force vector update:  F[DOF_v_N1] -= 91.8 kN
    (negative = downward force at junction, per standard FEM sign convention)

Step 3 — Equilibrium check at junction node N1 (after solve):
  Sum of element shear forces at N1 + external force = 0

  Let  V_A1_right = shear at right end of A1 (from stiffness solution)
       V_A2_left  = shear at left  end of A2 (from stiffness solution)

  Node equilibrium:  V_A1_right - V_A2_left + P = 0
                ⟹   V_A2_left  = V_A1_right + P

  In terms of element end forces (sign convention: fe[0]=Vleft upward,
  fe[2]=Vright downward = -(internal shear)):
    reactions[N1] = fe_A1[2] + fe_A2[0]
                  = (reaction from A1 at its J end)
                  + (reaction from A2 at its I end)
                  = P + wu_A1·L₁ + wu_A2·L₂  (split between nodes by stiffness)
  External force at N1: -P (downward from B)
  Net:  reactions[N1] - P  =  0  ✓   (equilibrium satisfied)

Step 4 — Iterative convergence:
  The engine iterates (up to 20 cycles, tol = 0.1%) extracting B's actual
  reaction from the stiffness solution and re-applying as P.
  Convergence is typically achieved in 2–3 iterations because:
    - P depends only on B's own deflection (weak coupling)
    - B's boundary conditions are fixed (no interaction back from A1/A2)

  Iteration   P (kN)    ΔP/P

E. MOMENT CONSISTENCY CHECK
═══════════════════════════════════════════════════════════════════════════════

Sign convention (ETABS-compatible):
  Mleft  = −fe[1]   (hogging at left end  → negative)
  Mright =  fe[3]   (hogging at right end → negative)
  Sagging (tension at bottom) is positive.

Junction moment equilibrium (Newton's 3rd Law):
  At node N1, the sum of element end moments + external moment = 0.
  No external moment is applied at N1 (secondary beam B carries shear only).

  fe_A1[3] + fe_A2[1] = 0
  ⟹  fe_A1[3] = −fe_A2[1]
  ⟹  A1.Mright = fe_A1[3]  =  −fe_A2[1]  =  −(−A2.Mleft)  =  A2.Mleft

  ∴   A1.Mright  =  A2.Mleft      (moment continuity at C2)  ✓

BEFORE FIX (A1 and A2 in separate frames):
  A1 frame includes P  →  A1.Mright ≠ 0  (e.g. −48.2 kN·m)
  A2 frame excludes P  →  A2.Mleft  = 0  (simple beam, no junction load)
  Inconsistency: A1.Mright − A2.Mleft = −48.2 − 0 = −48.2 kN·m  ✗

AFTER FIX (A1 and A2 in same frame):
  Both share N1.  The stiffness solution enforces:
    d[2] (v_N1) identical for A1's J-end and A2's I-end
    d[3] (θ_N1) identical for A1's J-end and A2's I-end
  Therefore:  A1.Mright  =  A2.Mleft  (mathematically exact)  ✓

Example numerical verification (symmetric case, wu=48 kN/m, L₁=L₂=5 m,
P = 91.8 kN at junction, EI = 25 703 kN·m²):

  Solving the 4×4 free-DOF system:
    v_N1 = −PL₁³/48EI − 5wu·L₁⁴/384EI  (midspan deflection analogy)
    θ_N1 = 0  (symmetric loading → zero rotation at junction)

  A1.Mright (from stiffness solution) ≈ −(wu·L₁²/12 + P·L₁/8)
           ≈ −(48×25/12 + 91.8×5/8)  ≈ −(100 + 57.4)  ≈ −157.4 kN·m

  A2.Mleft  = A1.Mright ≈ −157.4 kN·m   (by symmetry and compatibility)  ✓

  BEFORE FIX:  A2.Mleft = −wu·L₂²/8 = −48×25/8 = −150.0 kN·m  (wrong,
               ignores P; differs from A1.Mright by 7.4 kN·m = 4.9%)

MOMENT CONSISTENCY STATUS:  CONFIRMED after fix — zero discontinuity at C2.
